# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[security advisory form](https://github.com/tec-smith/next-enterprise-starter/security/advisories/new),
not in a public issue. Include steps to reproduce and the impact you expect.
You'll get an acknowledgement within a few days.

## Scope

This policy covers the template itself. If you've built an app from it, you
are responsible for that app's security, including keeping dependencies up to
date (Dependabot is configured for this) and reviewing the defaults described
in the README's [security section](README.md#security).
